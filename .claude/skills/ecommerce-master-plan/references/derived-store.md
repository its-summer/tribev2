# 店铺板块 · 客户方案派生版（从 master 母版裁剪）

> 母版 = `master-plan-template.md`，**先读它的 Part A 原理**。本文件只写"店铺板块怎么裁剪母版"。销售心理层（母版 §1/2/9/10/11/12/13）原样套用。

## 主拉引擎与裁剪

- **主拉引擎**：客单价 + 转化率（店铺是流量的"承接器"与"变现器"）。
- **展开章**：§4 商品/竞品洞察、§7 客单价（选/排/组品）。
- **精简章**：§5 流量留一段，说明由短视频/达人/广告导入；店铺侧只做"承接转化"。

## 店铺特异性内容（替换/补进对应章）

### 强化 §4 → 商品与竞品洞察
- 竞品横向对标表（价格/规格/卖点/评价/BSR 排名）→ 反推本品定价带与差异化。
- 选品战略角色定义：引流品 / 主推品 / 利润品 / 形象品（与 §7 排品呼应）。

### 替换 §6（转化）→ 商详转化优化
- **Listing 优化**：标题（核心词+卖点+场景，含 SEO 关键词）、主图/白底图/场景图/卖点图序列、A+/图文详情结构、视频、评价/问答运营。
- **转化要素**：价格锚点呈现、限时活动、优惠券、运费门槛、信任标（认证/退换/正品）。

### 强化 §7 → 客单价工程
- **定价与利润测算**：成本+平台佣金+履约+投流分摊 → 反推可承受 ROAS 与最低售价；档位定价（单品/套装/订阅）。
- **排品**：购物车/橱窗顺序 1 号引流品 → 主推品 → 利润品（诱饵）→ 形象品。
- **组品/连带**：套餐、加价购、满减满赠提 ARPU。
- **库存**：爆品安全库存与补货节奏，避免断货掉权重。

## 数据分析（落在 §8/§12）
店铺看板核心指标：曝光→点击(CTR)→转化(CVR)→客单价(AOV)→GMV→退款率；按指标定位漏斗瓶颈，决定优化动作（标题/主图/价格/评价）。

## ⚠️ 合规
类目资质、功效宣称（药机法/景表法等）、价格不当表示（"史上最低"等）、知识产权（盗图/侵权）按目标市场过审。

## 报价档位（§10 套用母版 GBB）
旗舰：全店托管（选品+listing+定价+活动+数据） / 标准（主推）：核心 SKU listing 优化+月度数据 / 试运营：单品 listing 诊断+优化。
