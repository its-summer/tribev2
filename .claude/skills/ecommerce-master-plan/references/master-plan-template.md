# Part A · 设计原理（写之前先懂这个）

方案有两条并行主线：**增长方法论**（证明你能把货卖出去）+ **销售心理**（让决策层敢签字）。两者缺一不可——只有方法论会显得"不懂客户的怕"，只有心理话术会显得"虚、不专业"。

## 主线一 · 增长方法论（你的专业度）

### 第一性原理：GMV 三引擎
一切增长动作都从这条恒等式反推，**章节即由它拆出**：

```
GMV = 流量(Traffic) × 转化率(Conversion) × 客单价(AOV)
```

| 引擎 | 子策略 | 对应章节 |
|---|---|---|
| **流量** | 自然（引流内容矩阵 + SEO）+ 付费（分阶段放量、素材赛马） | §5 |
| **转化率** | 人货场 + 卖点测试 SOP（先放大、后收敛"黄金卖点"） | §6 |
| **客单价** | 人群分层 + 选品/排品/组品 | §7 |

> 任何"我们要把 GMV 做到 X"的承诺，都必须能拆成 流量×转化×客单价 的具体动作，否则就是空话。

### 分阶段 KPI 阶梯（降风险的核心装置）
增长不是一步到位，分三阶段、逐级抬目标、逐级抬预算——这同时是"先小后大、花钱买数据再花钱赚钱"的**承诺一致**与**损失厌恶**对策：

| 阶段 | 战略目的 | 预算 | 主考核 |
|---|---|---|---|
| **启动期** | 冷启动、自然流模型建立、攒素材/种子用户 | 极低 / ¥0 | 完播率、互动率、首批"王牌素材" |
| **测试期** | 小预算跑通"曝光→成交"链路，赛马出冠军素材 | 小 | CTR、CVR、ROAS 初模型 |
| **增长期** | 规模化复制成功模型 | 放大 | GMV、ROAS（盈利目标 ≥2.0） |

每阶段都给 **GMV / 粉丝 / 电商数据** 的量化目标 + **P&L 损益预估**，让财务和老板都能算账。

### 转化率方法论：人货场 + 卖点测试
- **卖点放大 → 数据收敛**：初期用多样呈现方式广泛测试所有卖点（可借 KANO 模型分基础/期望/魅力属性），再按互动+电商数据周度收敛，最终精炼出 1–2 个"黄金卖点"。
- **魅力属性视觉锤**：用差异化的视觉（颜色/形态/演示动作）锁定眼球、延长停留，停留↑→转化↑。
- **数据驱动复盘**：以数据看板驱动"人货场"持续优化，而非凭感觉。

### 客单价方法论：人群分层 + 选/排/组品
- **人群分层**：核心人群（基本盘）/ 拓展人群（如送礼场景）/ 机会人群（高性能溢价），每群配独立沟通策略。
- **选品**：定义每款的战略角色——引流品 / 主推品 / 利润品 / 形象品。
- **排品**：购物车顺序引导消费——1 号位引流品（低价高频引流、撬平台流量）→ 主推品 → 利润品（诱饵效应抬 AOV）→ 形象品（巩固高端定位）。
- **组品**：按人群打套餐提升 ARPU（如"办公室元气套装""送礼礼盒"），用"立省 XXX"框出价值感。

### 商品/竞品洞察（方法论的弹药）
用竞品数据表（价格/规格/性能/评价）做横向对标，反推**本品差异化卖点**与定价空间——这是后面所有内容与话术的事实依据，不能跳过。

## 主线二 · 销售心理（让客户敢签字）

> 与短视频派生版 `tiktok-short-video/references/client-proposal-template.md` 完全同源，此处提炼，细节见该文件。

### 第一性原理：方案只干两件事
1. **把客户的「风险/不确定性」降到他敢签字。**
2. **和客户对齐「什么叫成功」**，避免事后期望错位。
证据：80% 的 B2B 买家认为"避免做错决定"比"做对决定"更重要；44% 采购因"信息过载、没有清晰决策依据"流产。→ **清晰 > 华丽，降风险 > 秀肌肉。**

### B2B 买家 5 条铁律 → 对策
| 铁律 | 对策 |
|---|---|
| 损失厌恶主导（怕亏>想赢） | §11「风险与保障」：试运营、修改轮次、止损、阶段化预算 |
| 6–10 个决策人 | 摘要给老板、P&L/ROI 给财务、排期/配合给执行 |
| 信任是准入门槛 | §9 案例/证言/团队/方法论显性化 |
| 情绪先于逻辑 | §2 先证明"懂你"，再上策略 |
| 决策瘫痪 | 报价只 3 档；结尾只 1 个下一步 |

### Cialdini 六原则 → 落点
互惠（先送免费诊断/样片）· 承诺一致（首月试运营，先小后大）· 社会证明（案例/达人/评论）· 权威（方法论/数据/履历）· 好感（真的懂他人群）· 稀缺（档期有限，克制用）。

### 定价心理
锚定（先抛高档）· Good-Better-Best 三档（主推放中间，客单价 +15–25%）· 价值是**框出来的**（讲每档"解决什么/产出什么"，而非只列价）。

### 交付与留存（防 churn）
期望错位 = 头号流失原因；onboarding 期掉线 90% 会流失。→ 方案里就写清交付节奏、SLA、**首个价值里程碑**（尽早见效）。留存 +5% → 利润 +25–95%，方案要为续约埋线。
