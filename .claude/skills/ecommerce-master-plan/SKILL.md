# 跨境电商 · master 增长方案方法论

这是**所有对客方案的母版**。一份 master 方案要同时做到两件事：

1. **讲清怎么把 GMV 做起来**（增长方法论 = 专业度证明）。
2. **让客户敢签字**（B2B 买家心理 = 成交逻辑）。

各板块（短视频 / 直播 / 达人 / 店铺 / 广告）的客户方案，都是这份母版按"主战场"裁剪出的**派生版**，不另起炉灶。短视频板块的派生版已存在：`tiktok-short-video/references/client-proposal-template.md`。

## 第一性原理：GMV 三引擎

一切增长方案都从这条恒等式反推，章节即由它拆出：

```
GMV = 流量(Traffic) × 转化率(Conversion) × 客单价(AOV)
```

- **引擎一 · 流量**：自然（内容矩阵 + SEO）+ 付费（分阶段放量）双引擎。
- **引擎二 · 转化率**：人货场 + 卖点测试 SOP（先放大、后收敛出"黄金卖点"）。
- **引擎三 · 客单价**：人群分层 + 选品/排品/组品（引流品→主推品→利润品→形象品）。

三引擎之上再叠两层底座：**分阶段 KPI 阶梯**（启动→测试→增长，逐阶段降风险）与**本地合规**（市场法规红线）。

> 销售侧心理（第一性原理"降风险/对齐成功"、损失厌恶、6–10 决策人、Cialdini 六原则、定价锚定/GBB、防 churn 留存）见母版模板 Part A，与短视频派生版完全同源，不重复维护。

## 启动前必须确认的输入

缺以下信息先问用户，不要臆造：

- **产品/品牌**：品类、核心卖点（≤3）、客单价、差异化点、品牌调性。
- **市场/人群**：目标国家、核心人群画像与痛点、送礼/季节性等本地驱动。
- **平台/板块**：TikTok Shop / Amazon / 独立站；本方案以哪个板块为主战场（短视频/直播/达人/店铺/广告）。
- **目标/周期**：测试选题、引流、还是直接保 GMV/ROAS；启动预算与档期。
- **竞品**：对标品牌、可拿到的乐天/平台 TOP 榜或竞品数据（用于"商品洞察"章）。

## 工作流

1. **定主战场**：确认这份方案以哪个板块为核心（决定派生哪一版）。
2. **读母版原理**：先读 `references/master-plan-template.md` 的 **Part A**，理解每节"为什么这么写 / 对冲哪条心理 / 服务哪个引擎"。
3. **拆 GMV 目标**：用三引擎把客户的 GMV 目标拆成 流量×转化×客单价 的可执行动作，并落到 **启动/测试/增长** 三阶段的 KPI 阶梯（含 P&L 预估）。
4. **填母版模板**：用 **Part B** 逐节填 `{{占位符}}`；非主战场的引擎章可压缩为一段，主战场章充分展开。
5. **派生板块版**：若只交付单板块，对照 `references/derivation-guide.md` 取该板块的"主章/配套章"裁剪。
6. **合规自检**：对照目标市场法规（日本《药机法》《景品表示法》、美妆/保健功效宣称等）逐条过，⚠️ 标注存疑处并给合规替代表述。
7. **样例参照**：`references/example-livestream-mytrex.md` 是直播板块的填好版（脱敏自源方案），演示成品颗粒度。

## 实时检索

涉及以下内容用 WebSearch/WebFetch 查最新，不要凭记忆：

- 竞品价格/规格/TOP 榜（如乐天市场）、目标市场热搜词与话题标签。
- 平台广告产品与玩法（如 GMV MAX 的人群定向/出价逻辑）当期变化。
- 目标市场违禁词与品类限制（功效宣称尤其敏感）。

## 产出规范

- **结构化、可签约**：母版约 7 个核心章节、10±页；**执行摘要必须能独立读懂**（很多决策人只看这段）。
- **内部物料 vs 客户交付**：脚本、分镜、商品看板、Canva 设计是内部施工图，**不进**客户方案；客户方案 = 策略+排期+样片+预期+报价。
- **每个 GMV 目标都要落到动作**：禁止只写目标数字不写怎么达成。
- **报价只给 3 档**，主推放中间（GBB）；**结尾只给 1 个明确下一步**。
- **落地**：输出 Markdown，可直接粘贴进飞书 / Notion / 腾讯文档 / Zoom Docs；环境接了对应文档 MCP 时可一键生成在线链接。
