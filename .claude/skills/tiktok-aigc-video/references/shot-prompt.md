# 逐镜首帧图提示词结构

每个分镜首帧图的提示词按固定槽位拼，保证可控与一致。

## 提示词模板

```
[主体] {模特描述/复用 character sheet} {持产品/动作}
[产品] {真实产品名}，参考产品图，外观严格一致
[场景] {地点 + 时间光线}
[构图] {景别}，{机位角度}，9:16 竖构图
[风格] {色温/调性}，真实感商业广告质感，{品牌色}
[细节] {道具}，{表情情绪}
[负面] 多余文字水印、畸形手指、产品外观篡改、低清
```

## 示例（榨汁杯 镜头3）

```
[主体] 同 character sheet 的年轻女性，手持便携榨汁杯倒入水果
[产品] Portable Blender 380ml，严格参照 product_front.png，颜色与按钮一致
[场景] 明亮的早晨厨房台面，自然柔光
[构图] 中近景，平视微俯，9:16
[风格] 暖白色温，真实商业广告质感
[细节] 草莓蓝莓牛奶，轻松愉悦表情
[负面] 水印、畸形手指、产品外观改变、模糊
```

## 要点

- **人物**：永远写"同 character sheet"并挂参考图，不重新描述长相。
- **产品**：永远挂真实产品图做参考，提示词强调"外观严格一致"。
- **一镜一焦点**：一张图别堆太多动作，便于 i2v 稳定。
- 文字交给后期烧字幕，不要让生图模型写字（易乱码）。
