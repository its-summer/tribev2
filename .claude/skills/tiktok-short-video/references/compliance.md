# 合规自检清单

TikTok Shop 对夸大宣传、功效宣称、违禁词管控严格，违规会限流/下架/封号。每条脚本发布前自检。

## 高风险品类（额外谨慎）

- **美妆/护肤**：禁绝对化功效（"祛斑""根治""7 天美白"）。
- **保健/食品**：禁疾病治疗/预防宣称，禁"减肥""降三高"等功效。
- **医疗器械类**：禁医疗效果宣称。
- **3C/家电**：禁绝对参数夸大、禁与具体大牌直接贬低对比。

## 通用违禁/慎用表述

- 绝对化词：**最、第一、顶级、100%、永久、根治、彻底**（多数市场广告法/平台规则禁用）。
- 虚假紧迫/虚假折扣：编造"仅剩 X 件""原价"。
- 未经证实的功效与数据：无依据的"有效率 99%"。
- 诱导站外交易、引导加微信/私下成交。
- 侵权：未授权使用他人音乐、画面、品牌、明星肖像。

## 自检步骤

1. 通读脚本，标出所有功效/效果类表述。
2. 每条问：有无证据支撑？是否绝对化？是否属高风险品类禁区？
3. 不合规的改为**体验式/主观式表述**（"我用下来觉得……""帮我省了不少事"）。
4. 不确定的目标市场具体词，用 WebSearch 查该市场 TikTok 最新违禁词规则。
5. 用 ⚠️ 在交付物中标注被修改/存疑处，提示运营复核。

> 原则：宁可保守表述，也不冒限流封号风险。合规是带货可持续的前提。
