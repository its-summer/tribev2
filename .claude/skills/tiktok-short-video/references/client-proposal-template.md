# Part A · 设计原理（写之前先懂这个）

### 第一性原理：一份方案到底要干什么？
不是"展示我们多厉害"。一份方案只需完成两件事：
1. **把客户的「风险 / 不确定性」降到他敢签字。**
2. **和客户对齐「什么叫成功」**，避免事后期望错位。
其余所有章节都从这两点反推。证据：80% 的 B2B 买家认为"避免做错决定"比"做对决定"更重要；44% 的采购因"信息过载、没有清晰决策依据"而流产。所以**清晰 > 华丽，降风险 > 秀肌肉**。

### B2B 买家的 5 条铁律（决定话术）
| 铁律 | 含义 | 模板里的对策 |
|---|---|---|
| **损失厌恶主导** | 怕亏 > 想赢 | 设「风险与保障」章：试运营、修改轮次、止损机制 |
| **6–10 个决策人** | 财务/老板/执行各有诉求 | 执行摘要给老板，ROI 给财务，排期/配合给执行 |
| **信任是准入门槛** | 不信任直接出局 | 案例、证言、团队、方法论显性化 |
| **情绪先于逻辑** | 先共情才听方案 | 用「我们对你的理解」先证明"懂你"，再上策略 |
| **决策瘫痪** | 选项越多越不动 | 报价只给 3 档；结尾只给 1 个明确下一步 |

### Cialdini 六原则 → 落在哪一节
- **互惠**：方案里先送价值（免费诊断 / 1 条样片脚本）→ 客户产生回报心理。
- **承诺一致**：先小后大，用「首月试运营」让客户迈第一步。
- **社会证明**：案例、同行数据、达人/用户证言。
- **权威**：方法论、数据、团队履历。
- **好感**：表现出真的懂他的人群与痛点。
- **稀缺**：名额/档期有限、限时报价（用得克制，别像割韭菜）。

### 内容策略要展示的「消费心理学」（这是你专业度的证明）
客户买的是"你能让终端消费者下单"。所以策略章要显性体现 TikTok 冲动购买的三大驱动：
- **新奇**（算法分发偏好新内容）→ 选题持续迭代、A/B 测试。
- **紧迫**（限时/倒计时/库存）→ 脚本与挂车设计里嵌入紧迫感。
- **社会证明**（达人背书 + 实时评论）→ UGC/达人/评论区运营。
- 机制：短视频"声音开+强钩子"提升**情绪唤起**，唤起↑→自控力↓→冲动下单。钩子必须前 3 秒抓人。

### 定价心理
- **锚定**：先抛高档，让中档显得划算。
- **Good-Better-Best 三档**：多数人选中间档，客单价 +15–25%（decoy/Goldilocks 效应）。永远给 3 档，把你想卖的放中间。
- 价值是**被框出来的**，不是算出来的——讲清每档"解决什么/产出什么"，而非只列价格。

### 交付与留存（签了之后别掉）
- **期望错位 = 头号流失原因**；客户在 onboarding 期掉线，90% 会流失。→ 方案里就写清交付节奏、SLA、首个价值里程碑。
- **尽快触达"首个价值里程碑"**（如首条数据达标），让客户早点见到效果。
- 留存 +5% → 利润 +25–95%；所以方案要为"续约"埋线，不止赢首单。
