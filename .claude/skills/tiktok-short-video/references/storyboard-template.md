# 分镜表模板

把脚本拆成可拍摄的镜头，交付给拍摄/剪辑。

## 镜头表

| 镜头# | 时长 | 景别 | 运镜 | 画面内容 | 道具/场景 | 字幕 | 音效/BGM |
|---|---|---|---|---|---|---|---|
| 1 | 2s | 特写 | 推近 | 产品质感特写 | 产品+干净背景 | 钩子大字 | 重音卡点 |
| 2 | 3s | 中景 | 固定 | 痛点场景演示 | 真人+场景 | 痛点词 | 旁白 |
| ... | | | | | | | |

## 节奏与剪辑

- 平均 **每 1.5–3 秒切一个镜头**，保持节奏，防止划走。
- 卡点剪辑：关键卖点/转折踩在 BGM 重音上。
- 字幕全程在线（很多人静音刷），字号大、停留够。
- 结尾 CTA 镜头停留 2s 以上，给足下单引导时间。

## BGM / 标签

- BGM 优先用平台**当前热门音乐**（用 WebSearch 查目标市场近期热门 sound）。
- Hashtag：1 个大词 + 2–3 个精准品类词 + 1 个活动/挑战标签。
