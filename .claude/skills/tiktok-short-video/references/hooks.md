# 0–3 秒钩子库

前 3 秒决定完播率。钩子 = 一句话 + 一个强画面。每条选题给 3 个备选，A/B 测试。

## 钩子句式（口播/字幕）

- **悬念**："别再这样用 XX 了，难怪……"
- **直给结果**："这就是我再也不买 XX 的原因。"
- **提问**："你也有 XX 的烦恼吗？"
- **数字/对比**："9.9 刀的它，竟然比 50 刀的还好用。"
- **反常识**："越贵的 XX 反而越伤手。"
- **身份点名**："留学生宿舍党，这个一定要囤。"
- **冲突/打脸**："朋友说我交智商税，结果……"
- **限时紧迫**："这波活动今晚结束，错过等一年。"

## 强画面钩子（前 3 秒画面）

- 极限测试瞬间（泼水、摔、暴力测试）
- 强烈 Before/After 对比
- 特写质感 + 快速运镜
- 真人夸张表情/反应
- 把产品放进一个出乎意料的场景

## 自检

- 3 秒内是否出现"利益点"或"冲突"？
- 是否一眼能看出与目标人群相关？
- 画面与口播是否互相加强而非重复？
