# TikTok 带货短视频方法论

为 TikTok Shop 产品产出**可直接拍摄/剪辑**的内容物料。核心原则：先钩子、强卖点、快节奏、明确 CTA、规避合规风险。

## 启动前必须确认的输入

缺以下信息时先向用户提问，不要臆造卖点：
- **产品**：品类、核心卖点（3 个以内）、客单价、差异化点
- **人群**：目标市场/国家、性别年龄、使用场景、核心痛点
- **品牌**：调性（专业/搞笑/亲和）、是否有真人出镜、语言
- **目标**：本批视频是测试选题、引流还是直接转化

## 工作流

1. **选题** → 用 `references/topic-angles.md` 的角度框架，一次产出 5–8 条选题，每条标注：角度、目标人群、预期钩子、形式（口播/测评/情景/开箱/对比）。
2. **钩子** → 用 `references/hooks.md` 为选定选题写 3 个 0–3 秒钩子备选。
3. **脚本** → 用 `references/script-template.md` 写逐句脚本（时间轴 + 口播 + 画面 + 字幕）。
4. **分镜** → 用 `references/storyboard-template.md` 出镜头表（运镜、景别、道具、BGM、节奏）。
5. **合规自检** → 对照 `references/compliance.md` 逐条过违禁词与夸大宣传。
6. （可选）**爆款拆解 / 复盘**：拆解对标视频的钩子-节奏-CTA 结构，或按完播/互动/转化复盘迭代。

## 实时检索

涉及以下内容时用 WebSearch/WebFetch 查最新信息，不要凭记忆：
- 当前热门 BGM、挑战赛标签、平台热点梗
- 目标市场的 TikTok 违禁词/品类限制（尤其美妆、保健、宣称功效类）
- 对标账号近期爆款

## 产出规范

- 结构化输出（表格/分镜表），让非内容岗同事能直接执行。
- 一条脚本默认控制在 **15–34 秒**（带货黄金时长），并给出可延展的 45s 版本建议。
- 每条都要有明确 **CTA**（购物车、左下角小黄车、主页链接等）。
- 合规存疑处用 ⚠️ 显式标注，给出合规替代表述。
