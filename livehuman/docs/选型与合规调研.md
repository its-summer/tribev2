# 选型与合规调研：AI 数字人 TikTok 直播带货（日本市场）

> 调研日期：2026-06。用途：评估"克隆真实员工 → AI 数字人 → TikTok 直播带货（日本）"
> 的可行性、工具选型与合规风险。结论按重要性排序：**合规 > 工具**。

---

## 0. 一句话结论

1. **先解决合规，再谈工具。** TikTok Shop 2026-05 新规疑似**禁止 AI 配音 / 数字人 / 预录 / 循环画面**用于带货直播——这对所有工具（万兴、自建、HeyGen）一视同仁，决定整个方向能否成立。**必须先就日本市场核实清楚（见第 3 节清单）。**
2. **万兴播爆达不到你的"真人互动感"需求。** 它的实时互动是**关键词触发 + 预录回复**（非 LLM 智能问答），日语质量无独立验证，真人感中等偏下，定位是中小/短视频工具。
3. **若政策允许 AI 主播**：要"真智能互动"，我们自建的 Claude 大脑 + 一个好的口型引擎，比万兴更贴需求——但这要先过合规这关才值得投入。

---

## 1. ⚠️ 关键合规发现：TikTok Shop 禁 AI 主播带货

这是**平台政策**，与用什么工具无关。

TikTok Shop 于 **2026-05-23** 发布《高质量视频与直播要求》(Requirements for
High-Quality Videos and LIVEs)，在带货直播 / 可购视频中**禁止**：

- **AI 合成语音**（TTS / 克隆音色都属于）
- **预录旁白、电台式音轨、循环画面、幻灯片、录屏**
- **非真人的动画形象 / 数字人占屏 > 50%**

并**要求**：真人实时口播、露脸、出镜实物、真实场景、有镜头移动。
**执行**：扣佣金、下架内容、封号；对所有卖家与达人生效。

来源（多家独立媒体证实）：
- https://www.pymnts.com/news/ecommerce/2026/tiktok-shop-bans-ai-voices-from-livestreams/
- https://ppc.land/tiktok-shops-quality-rules-ban-ai-voices-and-still-images-from-lives/
- https://www.shopifreaks.com/tiktok-shop-bans-ai-generated-voices-and-static-image-content-from-its-promotional-livestreams-and-shoppable-videos/
- https://www.darkroomagency.com/observatory/what-brands-need-to-know-about-tiktok-new-rules-2026

### 边界与未定项（别过度恐慌，但要核实）
- 这是 **TikTok Shop（带货电商）** 的规则；**普通 TikTok LIVE（娱乐直播 + AI 标注）**
  是另一套，AI 虚拟主播在标注前提下可能仍可做——但那不是直接挂车成交。
- 政策在演变，**各地区（含日本）执行力度可能不同**，需按目标市场核实。
- 参考：中国抖音允许 AI 直播，但**数字人须实名报备 + 必须真人值守**
  （https://www.sixthtone.com/news/1015782）。

### TikTok LIVE 通用门槛（与工具无关）
- 开播一般需 **1000+ 粉丝**；账号 16+（收礼物 18+）。
- 带货须开启 **Commercial Content** 开关，否则限流/中断。
- **AI/合成内容须显著标注**（2026 起未标注可直接判罚、封流）。

## 2. 万兴播爆（Wondershare Virbo）实测深挖

针对需求：克隆员工、日语、真人互动感、带货。结论：**不达标**。

| 维度 | 实际情况（独立来源） | 是否满足需求 |
|---|---|---|
| 实时互动 | 官方文档载明：**关键词触发 + 预录回复**（每词≤5条，自动填[昵称]/[国家]）；答不了没预设过的问题，需真人手动打字 | ❌ 非智能问答，**卡死核心需求** |
| 日语质量 | 仅官方宣传支持多语言含日语；**无任何独立的日语语音自然度 / 口型准确度实测**；口型模型多按英文训练，日语音调/长短音常偏弱 | ⚠️ 未验证、有风险 |
| 真人感 | 独立测评：表情僵硬、动作机械重复、长句口型崩、嘴部失真；"100%相似"为营销话术 | ❌ 中等偏下，非专业带货级 |

| 可用性 | **存疑**：有 Wondershare 下线通知（标题是 *VirtuLook*——另一产品，疑似混淆），部分来源称 Virbo 2025-06-30 停运；但商店/直播指引/2026评测页又都还在 | ⚠️ 需上官网亲验能否注册 |

## 3. ✅ 合规核实清单（最该先做的事）

在往任何工具/方案继续投入前，按下面逐条向 **TikTok 官方政策页 / TikTok Shop 后台 /
你的 TikTok 客户经理（Account Manager）** 确认。建议留书面答复。

### A. TikTok Shop 带货（你的主目标）
- [ ] 日本 TikTok Shop 是否适用 2026-05《高质量视频与直播要求》？
- [ ] **AI 合成语音**在带货直播是否一律禁止？（你的 TTS/克隆音色是否被判违规）
- [ ] **数字人/虚拟形象**作为主播是否被禁？"占屏 > 50%"如何界定？
- [ ] 是否存在"真人 + 数字人辅助"的合规组合方式？
- [ ] 违规后果（扣佣/下架/封号）与申诉路径？

### B. 普通 TikTok LIVE（娱乐直播，非 Shop）
- [ ] AI 虚拟主播 + 显著 AIGC 标注，是否允许？
- [ ] 能否走"普通 LIVE 做内容/互动 → 站外/橱窗引流成交"绕开 Shop 直播限制？
- [ ] 日本市场 AIGC 标注的具体形式要求（画面文字/口头声明/标签）？

### C. 真人/肖像与数据
- [ ] 克隆真实员工：是否需要 TikTok 侧实名/授权报备？
- [ ] 是否要求**真人值守**（像抖音那样）？
- [ ] 员工书面授权范围/期限/撤回（我们平台已强制留痕，见 `consents/`）。

### D. 账号资格
- [ ] 目标账号粉丝是否达开播门槛（≥1000）？
- [ ] 是否已开通日本 TikTok Shop 卖家 + 直播带货权限？

## 4. 据核实结果的三种走向

| 核实结果 | 建议走向 |
|---|---|
| TikTok Shop 明确禁 AI 主播带货 | 放弃"数字人直接 Shop 带货"；改走 **普通 LIVE（标注AI）+ 站外引流**，或回到**真人+AI 辅助**模式 |
| 普通 LIVE 允许标注 AI 主播 | 用**我们自建平台**（Claude 智能互动 + 多语言 + 口型同步）做娱乐/种草直播，成交走橱窗/站外 |
| 政策允许且要高真人感 | 自建平台 + 口型引擎（MuseTalk 自建 / 商业引擎），**万兴不选**（互动脚本化、日语未验证） |
