# 员工录制素材

存放员工录制的产品讲解视频，供生成数字人使用。

## 本土员工 + 母语录制（推荐策略）

尽量让**目标市场的母语员工用母语录制**：

- 克隆音色会带上录制者的口音。西语母语员工录西语 → 数字人在西语市场直播最地道；
  让中文母语员工录的音色去说西语，会带明显中文口音，本土观众一听就出戏。
- 因此生成流水线把**母语默认设为该数字人的主直播语言**（`--native-language`）。
- 一个市场配一位本土员工：面向西语区用 Lucía（母语 es），面向日本用一位日语员工，以此类推。

跨语言直播仍然可行（克隆音色经 `eleven_multilingual_v2` 能说 30+ 语言），
但带源语言口音，适合做次要语言；主力市场建议用对应母语员工的数字人。

## 录制要求（保证克隆质量）

- 时长：3~10 分钟，干净人声 1~3 分钟即可克隆。
- 环境：安静无回声、无背景音乐、无他人说话。
- 设备：麦克风贴近，避免爆音；竖屏 9:16，光线均匀（形象循环要用画面）。
- 内容：自然口语化地讲解产品，覆盖主要卖点（这些会成为直播话题池）。
- 语言：全程用母语，语气自然，不要念稿腔。
