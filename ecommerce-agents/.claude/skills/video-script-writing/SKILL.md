# TikTok 带货短视频脚本

为任意品类产品产出可直接拍摄的带货脚本。

## 前置
读取客户档案：产品卖点、目标市场与语言、品牌调性（语气/禁用词）、对标爆款。
可先用 Tavily 调研该品类近期热门视频结构与钩子。

## 黄金结构（15–45 秒）

| 段落 | 时长 | 目标 | 要点 |
|---|---|---|---|
| 钩子 Hook | 0–3s | 留住人 | 痛点提问/反差/结果前置/争议；前3秒决定完播 |
| 痛点 Problem | 3–8s | 共鸣 | 具体场景，让目标人群"对号入座" |
| 方案 Solution | 8–20s | 种草 | 产品如何解决，展示核心卖点与使用瞬间 |
| 信任 Proof | 20–30s | 降低顾虑 | 效果对比/数据/评价/资质 |
| 行动 CTA | 末尾 | 转化 | 明确下一步 + 紧迫感（限时/库存/优惠） |

## 输出格式（每条脚本）

```
选题：｜目标人群：｜钩子类型：
─────────────────────────────
| 时间 | 口播台词 | 画面/分镜 | 字幕 | 备注(运镜/BGM/道具) |
─────────────────────────────
封面文案建议：
标签/话题建议：
合规自检：☐ 无虚假功效  ☐ 无违规价格宣称  ☐ 符合品牌禁用词
```

## 原则
- 一条脚本只打一个核心卖点，不贪多。
- 钩子至少给 3 个备选做测试。
- 语言/梗/审美按**目标市场**本地化，不照搬国内话术。
- 严格过客户禁用词与目标市场广告合规。
- 成片可交 short-video-maker(MCP) 出原型，封面交 Canva(MCP)。
