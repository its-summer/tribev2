# TikTok Shop 店铺健康诊断

对任意品类客户店铺做标准化体检，输出"问题清单 + 影响 + 优先级 + 建议动作"。

## 前置
读取客户 `client-profile.md`，确认 shop_id、目标市场、授权 API 范围、品类与合规敏感点。数据通过 TikTok Shop Partner API 拉取（见 `integrations/tiktok-shop-partner-api.md`）。

## 六大诊断维度（逐项打分：健康 / 注意 / 风险）

1. **店铺资质与评分**
   - 店铺体验分、差评率、IPM/纠纷率、违规计分是否接近处罚阈值。
2. **商品健康**
   - 在售 SKU 数、滞销/零动销占比、类目挂错、属性缺失、主图/标题不合规、价格异常。
3. **转化漏斗**
   - 曝光 → 点击(CTR) → 加购 → 下单(CVR) → 支付，定位漏斗最大跌点。
4. **流量结构**
   - 自然/短视频/直播/广告/达人各渠道占比与趋势；是否过度依赖单一渠道。
5. **履约与物流**
   - 出货时效、超时未发率、取消率、退款/退货率、物流时效达标率。
6. **合规风险**
   - 功效/价格违规文案、侵权、禁限售、目标市场本地化合规（标签、认证）。

## 输出格式

```
店铺诊断报告 — <客户> / <shop_id> / <周期>
总体：🟢/🟡/🔴 一句话结论
─────────────────────────────
| 维度 | 状态 | 关键发现 | 影响 | 优先级 | 建议动作 |
（按优先级 P0/P1/P2 排序，P0 = 影响 GMV 或有处罚风险，需立刻处理）
─────────────────────────────
下一步（本周可执行的 3 件事）：
对照 KPI 的差距与归因：
```

## 原则
- 先定位"最大单点损失"，不要面面俱到。
- 每个问题都要给**可执行动作**和**预期影响**，不要只描述现象。
- 改价/上下架/改库存类修复动作只给方案，由 shop-ops-tsp 报批后执行。
